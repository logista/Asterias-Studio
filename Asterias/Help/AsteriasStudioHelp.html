Asterias Studio Help

Asterias Studio creates layered procedural images by combining generator families, palettes, sizes, and seeds.

Create an Image

  1. Choose a canvas size from the Pattern controls.
  2. Choose a palette, or use User Defined to pick five custom colors.
  3. Open Generators to include or exclude specific generator families.
  4. Click Start Generation or Regenerate.

Seeds

Turn off Random Seed to enter a fixed numeric seed. Reusing a seed with the same settings produces a repeatable recipe.

Tiling

Enable Tiling when the result should wrap cleanly across its edges for backgrounds, textures, or patterns.
