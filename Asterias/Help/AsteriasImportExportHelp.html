Import and Export Help

Asterias Studio can save images with embedded recipe metadata and restore settings from those images later.

Export Images

  1. Generate an image.
  2. Choose PNG or TIFF in the Export controls.
  3. Click Export Image and choose a destination.

Import Recipes

Drag an exported Asterias PNG or TIFF file onto the canvas. If recipe metadata is present, the app restores the seed, size, palette, tiling option, and selected generators.

Compatibility

Recipe metadata records the app build and generator sequence. Older exports remain readable, but generation output may vary after generator behavior changes.
